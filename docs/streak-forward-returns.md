# TQQQ 연속 상승 이후 성과

"3일·4일·5일 연속 상승한 뒤, 누적 상승률 구간별로 5/10/20일 뒤 가격과 하락폭은 어떻게 되는가"를
실제 TQQQ(2010~)와 합성 TQQQ(1999~)에서 각각 집계한 결과다.

재현:

```
node scripts/streak-forward.mjs            # 실제 TQQQ, 콘솔 표
node scripts/streak-forward.mjs --sim      # 합성 TQQQ(닷컴·금융위기 포함)
node scripts/streak-forward.mjs --md --csv # 이 문서의 표 + docs/streaks*.csv
```

## 정의

- **상승일**: 종가 > 전일 종가
- **연속 N일**: 앞뒤가 끊긴 '정확히 N일' 연속 상승 구간. 5일 연속을 3일 연속에도 중복 집계하지 않는다.
- **진입**: 연속 상승 마지막 날 종가 — 즉 "연속 상승을 확인하고 그날 종가에 샀다면"
- **누적상승률**: 연속 시작 직전 종가 → 연속 마지막 날 종가
- **5/10/20일**: 이후 거래일 기준 수익률(종가/진입가 − 1)
- **MDD**: 진입 후 해당 구간 안에서 종가가 진입가 대비 가장 많이 빠진 폭
- 종가 기준이며 배당·세금·거래비용은 반영하지 않았다.

## 요약

1. **연속 상승 직후 5일은 기대값이 마이너스다.** 실제 데이터에서 3·4·5일 연속 뒤 5일 수익률 평균은
   −0.9 ~ −2.2%, 승률 38~46%. 아무 날이나 샀을 때(+1.0%, 승률 59%)보다 확연히 나쁘다.
   단기적으로는 되돌림이 온다는 뜻이다.
2. **20일까지 보면 대체로 회복하지만 기준선에는 못 미친다.** 20일 평균은 +1.4 ~ +2.9%로 플러스지만
   기준선 +4.0%보다 낮다. "연속 상승 후 진입"은 그 자체로 이득이 되는 타이밍이 아니다.
3. **누적 상승률이 클수록 나빠진다 — 특히 짧은 연속일수에서.** 4일 연속 + 누적 15% 이상은
   20일 평균 −4.1%, 승률 43%, 평균 MDD −14.7%로 전 구간 중 가장 나쁘다.
   합성 데이터(표본 2배)에서는 3일 +15%↑(−6.5%), 4일 +15%↑(−5.0%)가 함께 최악이다.
   3~4일 만에 15% 넘게 튀는 건 대개 폭락 중의 반등이라 그 뒤가 다시 나쁘다.
4. **반대로 '천천히 오래' 오른 쪽은 무난하다.** 4일 연속 + 누적 5% 미만은 20일 평균 +5.3%, 승률 85%,
   최악 MDD −9.2%로 전 구간에서 가장 안정적이다(표본 13개로 작다).
   5일 연속은 누적이 커도 크게 나빠지지 않는다(실제 +15%↑ 20일 +3.6%, 합성 −0.9%).
5. **하락 위험은 어느 구간이든 두 자릿수로 본다.** 20일 평균 MDD는 −8 ~ −15%,
   최악은 2020년 코로나(−68%)·2022년 하락장(−30% 내외)에서 나온다.
   표본이 구간당 5~66개로 작아 각 숫자는 방향성 참고용이다.
